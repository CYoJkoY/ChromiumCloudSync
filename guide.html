User Guide

A simple GitHub Gist sync tool.

Quick start

Create a private Gist or bind an existing one. The extension then reads and writes one shared JSON sync state.

What is stored

Tabs, tab groups, bookmarks, extension inventory, selected extension settings, sync metadata, tombstones, and conflict records are stored in the Gist.

The sync state is stored as normal JSON. The extension does not encrypt or decrypt the sync payload.

Sync model

There is no device registry. Every browser reads the same Gist state and merges it with the local base snapshot before writing the next revision.

Automatic sync

Automatic sync is disabled by default. The default interval is five minutes. You can enable it in Settings and choose another interval.

History and rollback

GitHub Gist keeps the revision history. The extension does not create separate history files. Rollback writes the selected revision back as a new current revision.

Privacy

New Gists created by the extension are private. GitHub access is authenticated with your Token. Because the sync state is stored as JSON, treat access to the Gist as access to the synced data.

Troubleshooting

If an older Gist reports that it uses the removed encryption format, open it once with v1.5.x and perform a successful sync so the extension can migrate it to the new plaintext format.
